# Project Instructions

1. **No git operations.** Do not run any git commands (commit, push, pull, branch, reset, etc.). The user handles all git work manually.

2. **No delete operations without approval.** Before deleting any file, folder, or code, explain what will be deleted and give a valid reason. Wait for explicit approval before acting — this applies even in automatic/auto-accept mode.

3. **The application cannot be run here.** It needs credentials that only exist in the client environment. Do not try to run the app or its tests. Before changing any code, trace the logic end to end and make sure the change is correct by reasoning alone.

4. **Keep code simple and modular.**
   - Write simple, minimal logic. Avoid bloated or over-engineered code.
   - Build independent, self-contained modules and functions that can be reused in any project by just importing and calling them.
   - Plan the code structure with this reusability in mind when designing or changing the codebase.
